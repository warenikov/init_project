# Использование в других агентах

Скиллы написаны по открытому стандарту [Agent Skills](https://agentskills.io): папка с `SKILL.md`, где во frontmatter обязательны только `name` и `description`, а тело — обычный markdown. Такой файл понимают Claude Code, OpenAI Codex, Cursor, GitHub Copilot, VS Code, Gemini CLI, opencode, Goose и ещё несколько десятков инструментов.

Внутри нет ничего, что зависит от Claude: ни вызовов инструментов, ни MCP, ни скриптов. Только инструкции текстом и markdown-шаблоны. Любая модель, которой этот текст попал в контекст, может по нему работать.

## Что вендор-специфично (и безопасно игнорируется)

| Что | Где | Другие агенты |
|---|---|---|
| `.claude-plugin/` | корень репозитория | не читают, мешать не мешает |
| `allowed-tools:` во frontmatter | оба `SKILL.md` | игнорируют |
| `argument-hint:` | `task-log` | понимает часть агентов |
| Упоминания «скилл» и `/имя` | тексты | читается как «инструкция», работает и при ручном вызове |

Обязательное по стандарту соблюдено: `name` в нижнем регистре через дефис и **совпадает с именем папки**, `description` объясняет и что делает, и когда применять.

## Как подключить

**1. Агент поддерживает Agent Skills.** Скопируй папку скилла туда, где твой инструмент ищет скиллы (обычно `.agent/skills/`, `.<инструмент>/skills/` в проекте или соответствующая папка в домашнем каталоге — смотри документацию инструмента):

```bash
git clone https://github.com/warenikov/init_project.git
cp -r init_project/skills/init-project <папка-скиллов-твоего-агента>/
cp -r init_project/skills/task-log     <папка-скиллов-твоего-агента>/
```

**2. Агент работает по `AGENTS.md` / `GEMINI.md` / правилам Cursor.** Положи скилл в проект и добавь одну строку в файл инструкций агента:

```markdown
Инициализация документации проекта — по инструкции `.agent/skills/init-project/SKILL.md`,
ведение истории задач — по `.agent/skills/task-log/SKILL.md`.
```

**3. Чат без доступа к файлам** (веб-интерфейс любой модели). Собери всё в один текст и вставь его в диалог:

```bash
./bin/bundle.sh > init-project-prompt.md
```

Скрипт склеивает `SKILL.md`, все справочники и все шаблоны в один файл с оглавлением.

## Модели послабее

Полный маршрут — разведка, опрос блоками, план, генерация — требует дисциплины: слабая модель склонна вывалить все вопросы разом, пропустить разведку и насочинять правдоподобных фактов вместо «не знаю».

Подстраховка уже в тексте: в `SKILL.md` есть раздел «Если ты читаешь только этот файл» — шесть железных правил, пять обязательных вопросов и минимальная структура. Этого достаточно, чтобы результат был бедным, но не вредным.

Если запускаешь на маленькой модели, помогает вести её по одному шагу за запрос: сначала «сделай разведку и покажи, что нашёл», потом «задай блок A», потом «создай файлы».
