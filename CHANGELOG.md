# Changelog

## 1.2.0 — 2026-09-20

`task-log` подстраивается под чужую структуру документации.

- Шаг 0: перед любым действием скилл определяет папку журнала, шаблон, **именование файлов по существующим записям**, разделы индекса, где лежат правила процесса и префикс тикетов. Структура проекта главнее умолчаний скилла; существующие файлы не переименовываются.
- Работает на проектах, где документация создана не `init-project`, а другим скиллом или руками.
- Сбор знания при закрытии задачи учитывает альтернативные имена файлов (`servers.md` наряду с `environments.md`).

## 1.1.0 — 2026-09-20

Переносимость на другие агенты и модели.

- `AGENTS.md`: как подключить скиллы в Codex, Cursor, Copilot, Gemini CLI, opencode; что из frontmatter вендор-специфично.
- `bin/bundle.sh`: сборка всех инструкций и шаблонов в один markdown для чатов без доступа к файлам.
- В `init-project/SKILL.md` — раздел «Если ты читаешь только этот файл»: железные правила, обязательные вопросы и минимальная структура для агентов, которые не подтягивают `references/`.

## 1.0.0 — 2026-09-20

Первая версия.

- Скилл `init-project`: разведка по репозиторию → опросный лист (8 блоков + быстрый путь) → `CLAUDE.md`-роутер и `docs/` в стиле Obsidian.
- Скилл `task-log`: ведение истории задач в `docs/history/` с переносом знания в тематические файлы при закрытии.
- Шаблоны документов, справочники по разведке, конвенциям Obsidian и составу структуры.
